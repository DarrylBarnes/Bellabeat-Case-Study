Bellabeat Marketing Strategy Case Study
================
Darryl Barnes
2025-05-01

- [Summary](#summary)

This project analyzes Fitbit activity and sleep data to uncover wellness
trends in women and generate marketing recommendations for Bellabeat’s
Leaf smart device.

## Summary

- Focus: Physical activity + sleep behavior
- Tools: R, NHANES (CDC), Fitbit Dataset (Kaggle)
- Key Outcome: Strategic marketing plan targeting women 16–30 and 50+
